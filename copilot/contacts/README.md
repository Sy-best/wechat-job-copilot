# 联系人档案目录

按需放 `contacts/<联系人显示名>.md`，文件名中的非法字符（如 `|`）会被替换为 `_`。
该文件优先级高于通用口径包，用于记录「对这个人已经说过什么」——例如已报过的薪资、
推过的岗位、当前沟通阶段，避免 AI 下一轮自相矛盾。

**这些文件含个人隐私，全部被 gitignore，请勿提交到任何公开仓库。**

格式示例（纯文本/Markdown 均可）：

```
# 联系人档案 · 示例

## 已说出口的数据（不能再矛盾）
- 2026-01-01 已告知：期望 xx，当前 xx

## 沟通状态（内部判断依据，禁止转述）
- 对方在推什么方向的岗位
- 未到 offer 阶段

## 回复风格
- 稍微口语化，但仍要稳
```
